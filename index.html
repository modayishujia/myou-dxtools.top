Capabilities

一个 skill，替代一整个舆情团队

无需自建系统、无需服务器、无需账号。把 skill 装进你的 AI 助手，它就成为一个全天候的网络情报分析师。

🎯

一句话建监测

输入关注点即自动生成监测方案：关键词矩阵、数据源、采集频率、预警规则，确认后持续运行。

📡

全网提及采集

公众号/小红书/微博/新闻/抖音/X 全覆盖，含评论区深度采样、传播路径（首发→转发链→大 V）。

🧠

不设固定套路

每轮先盘点实际数据，再单独生成专属分析逻辑；8 维度只是候选池，指标基准随话题自校准。

🚨

分级预警

声量突增、负面占比、新关键词、KOL 负面、情感转向等按红/橙/黄/蓝分级，输出结构化告警可接企业微信/飞书。

📄

报告三层

决策者看一页摘要，执行看标准报告，危机看 10 分钟快报；每轮自动生成「相比上轮的变化」。

🛟

危机处置闭环

预警→快报→处置建议（含对外口径）→预案库沉淀→72 小时复盘，处置经验持续累积。

⚖️

竞品对标

本品 vs 竞品的声量份额（SoV）、情感与内容类型占比横向对比，不臆造数字。

🧩

5 种场景预设

舆情监控 / 行业调研 / 产品发布 / 投资研究 / 金融单品追踪，按话题自动匹配分析链路。

Install

怎么安装（3 分钟）

前提：你有一个支持「技能（Skills）」的 AI 助手（Claude Code、WorkBuddy 等皆可）。skill 只是一份方法论文档，装上就能用。

1对你的助手说一句话

直接对你的 AI 助手说下面这句话，它会把 skill 从 GitHub 自动装好（Claude Code、WorkBuddy 等支持技能安装的助手都可以）：

自然语言
安装这个 skill https://github.com/modayishujia/myou-data-research.git

也可以说：「帮我把 https://github.com/modayishujia/myou-data-research.git 这个 skill 装一下」。

2重新打开助手，直接开用

无需任何配置。对助手说一句话即可触发（见下方「怎么使用」）。

  • 搜索/抓取能力：助手需具备联网搜索（websearch）与网页抓取（webfetch）能力，用于新闻、公众号、研报。
  • 浏览器能力（可选但推荐）：采集小红书/抖音/微博/X 的站内数据建议使用可控制浏览器的工具（如 Kimi WebBridge）或已登录的浏览器会话。
  • 数据本地存储：所有数据以 markdown 增量写入 ~/.local/share/data-research/话题/，无数据库、无云端，随时可打开编辑。
  • 全程免费：skill 本身免费；运行成本仅为你的助手机器人额度。
